# The Client - Website
Voor de website https://visualthinking.school/ is er een redesign ontworpen waarvan deze ontwikkeld dient te worden. Een figma is aangeleverd voor de desktop versie en een aantal mobiele weergaves, zie hiervoor https://www.figma.com/design/L6Xz5TeiDxiyCdtvC94zdO/Prototype-Visual-Thinking?node-id=272-1359&p=f&t=MuKxXWiZBol5WlN7-0. Onze taak is om de ontbrekende mobiele weergaven te ontwerpen en de website te ontwikkelen.

Bij de ontwikkeling hebben is een prioriteitenlijst gedeeld om de volgorde van ontwikkeling te delen. Zie deze hieronder:
-Must
Tekenmethode + detail

-Should
Homepage

-Could
Kennisclips
Artikelen
Inspiratie (& detail)
Over
Lesbrieftemplates

-Won't
Community
Uploaden

## Beschrijving
Momenteel is de tekenmethodes pagina in ontwikkeling en is te zien via de onderstaande link. Op deze pagina zijn de items onder de tekenmethode categorieën toe te voegen, waarbij het template zich continu blijft herhalen zonder extra code toe te moeten voegen. Functionaliteit is nog door te voeren, gezien de detailpagina's nog ontwikkeld moeten worden.

Link naar tekenmethodes pagina: https://stldevelopment.github.io/the-client-website/tekenmethodes
